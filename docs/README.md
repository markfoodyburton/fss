# FSS documentation

Start here if you are new to FSS. For *what FSS is and why*, read the
[top-level README](../README.md) first — it has the one-paragraph pitch
and a diagram.

## Map

| Directory | What's in it | Read it when you want… |
|---|---|---|
| [`spec/`](spec/) | ★ **NORMATIVE** — the FSS specification (7 short files) | the standard itself: the carrier, field types, atoms, protocols, conformance |
| [`design/`](design/) | Design notes, open issues, and per-transport rationale | the *why* behind a decision, or what's still unsettled |

## Suggested reading order

1. [`../README.md`](../README.md) — the pitch and the core idea.
2. [`spec/README.md`](spec/README.md) → `spec/00-object-model.md` … `06-conformance.md` — the standard, front to back.
3. [`../reference/examples/README.md`](../reference/examples/README.md) — something that actually builds and runs.
4. [`design/`](design/) — the architectural reasoning and open questions.
